# Tools Overview

PhonoLex provides four main tools for phonological analysis and word list generation.

## Custom Word Lists

The most powerful tool in PhonoLex. Build custom word lists using:

- **Phoneme patterns**: STARTS_WITH, ENDS_WITH, CONTAINS
- **Property filters**: 12 psycholinguistic properties across 4 domains
- **Exclusions**: Exclude specific phonemes
- **AND logic**: Combine multiple criteria

Perfect for creating targeted word lists for therapy, research, or education.

## Contrastive Sets

Research-based phonological intervention word lists:

- **Minimal Pairs**: Traditional target/substitute contrast (e.g., θ/t)
- **Maximal Opposition**: Two unknowns with major class difference (Gierut 1989-1992)
- **Multiple Opposition**: Global phoneme collapse treatment (e.g., t→d,k,g)

Based on evidence-based clinical research by Gierut and Storkel.

## Phonological Similarity

Find similar words using adjustable onset/nucleus/coda weights:

- **Presets**: Rhymes, alliteration, assonance, consonance, balanced
- **Custom weights**: Fine-tune similarity computation
- **Threshold control**: Adjust how similar words must be

Uses phoneme-sequence soft Levenshtein distance preserving consonant clusters and diphthongs.

## Lookup

Look up words and phonemes:

- **Word details**: View all phonological and psycholinguistic properties
- **Phoneme features**: 38 distinctive features from PHOIBLE
- **Phoneme comparison**: Feature-by-feature comparison
- **Feature search**: Find phonemes by distinctive features
