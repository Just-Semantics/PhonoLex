# Quick Start

Welcome to PhonoLex! This guide will help you get started with the tool.

## Accessing PhonoLex

Visit [phonolex.justsemantics.net](https://phonolex.justsemantics.net) to use PhonoLex in your browser. No installation or signup required!

## Your First Word List

1. Click on **Custom Word Lists** to expand the tool
2. Add a phoneme pattern (e.g., starts with /k/)
3. Optionally add property filters (frequency, imageability, etc.)
4. Click **Generate** to see your results
5. Export to CSV or copy individual words
