# Contrastive Sets

Generate research-based phonological intervention word lists using three evidence-based approaches.

## Overview

The Contrastive Sets tool provides three clinical intervention methods:
1. **Minimal Pairs** - Traditional approach
2. **Maximal Opposition** - Gierut (1989-1992)
3. **Multiple Opposition** - Global collapse treatment

## Minimal Pairs

Traditional phonological intervention using single-feature contrasts.

### Usage
1. Select "Minimal Pairs"
2. Enter **Target** phoneme (correct production)
3. Enter **Substitute** phoneme (child's production)
4. Choose position (initial/medial/final/any)
5. Set word length and complexity (optional)
6. Generate pairs

### Example
- Target: /θ/ (as in "think")
- Substitute: /t/ (child says "tink")
- Position: Initial
- Result: thin/tin, thick/tick, theme/team

## Maximal Opposition

Targets two unknown phonemes that differ maximally in features, including major class differences.

### Theory (Gierut 1989-1992)
- More efficient than minimal pairs
- Maximizes feature differences
- Promotes broader phonological change
- Targets major class differences when possible

### Usage
1. Select "Maximal Opposition"
2. Enter **unknown phonemes** (comma-separated)
3. System automatically identifies maximal pairs
4. Review feature differences
5. Generate word lists for selected pairs

### Example
- Unknown phonemes: /s, ʃ, θ, f/
- System suggests: /s/ vs /θ/ (both have major differences)
- Features differ: strident, distributed, anterior
- Pair example: seem/theme, sick/thick

## Multiple Opposition

Treats global phoneme collapse by contrasting the substitute with multiple targets simultaneously.

### Theory (Gierut 1989-1992, Storkel 2022)
- For children who collapse multiple phonemes to one
- Uses minimal sets (triplets, quadruplets, quintuplets)
- Addresses entire phonological pattern
- Promotes faster generalization

### Usage
1. Select "Multiple Opposition"
2. Enter **substitute phoneme** (what child says)
3. Enter **target phonemes** (what should be said)
4. System uses Maximal Classification + Maximal Distinction
5. Generate minimal sets

### Example
- Substitute: /t/
- Targets: /d, k, g/
- Result: Minimal sets like:
  - tie, die, guy, kite
  - tore, door, core, gore
