# PhonoLex Documentation

**PhonoLex** is a comprehensive phonological analysis and word list generation tool designed for speech-language pathologists, linguists, researchers, and educators.

## Features

- **Custom Word Lists** - Pattern matching with phonological, lexical, semantic, and affective property filters
- **Contrastive Sets** - Research-based phonological interventions: minimal pairs, maximal opposition, and multiple opposition
- **Phonological Similarity** - Find similar words with adjustable onset, nucleus, and coda weights
- **Lookup** - Word lookup, phoneme features, phoneme comparison, and feature-based phoneme search

## Quick Start

Visit [phonolex.justsemantics.net](https://phonolex.justsemantics.net) to start using PhonoLex immediately in your browser. No installation required!

## Data & Methodology

PhonoLex combines:

- **24,744 English words** from the CMU Pronouncing Dictionary
- **38 distinctive phonological features** from the PHOIBLE database
- **8 psycholinguistic properties** from 4 major research datasets (SUBTLEX-US, Glasgow Norms, Brysbaert et al., Warriner et al.)
- **Phoneme-sequence similarity** using soft Levenshtein distance preserving consonant clusters and diphthongs
