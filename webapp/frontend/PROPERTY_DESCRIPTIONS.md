## Usage Guidelines

1. **Tooltips**: Use "Tooltip" version for table headers and hover text
2. **Builder Filters**: Use "Long" version for filter descriptions
3. **Search Tool**: Use "Short" version for compact displays
4. **Consistency**: Always include scale information in parentheses
5. **Citations**: Include source/author in Builder descriptions for attribution
